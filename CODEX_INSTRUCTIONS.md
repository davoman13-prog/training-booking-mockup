# Codex Instructions

Build a complete clickable mockup only.

Rules:

1. Do not create a database.
2. Do not create backend APIs.
3. Do not create real authentication.
4. Do not create payment processing.
5. Do not send emails.
6. Do not create real PDF generation.
7. Use static dummy data only.
8. All forms should look functional but only show mock success messages.
9. Keep the code simple and easy to extend.
10. Use TypeScript types.
11. Put mock data in /src/data/mockData.ts.
12. Put shared types in /src/types/index.ts.
13. Use reusable components.
14. Make every page reachable through navigation or buttons.
15. Run npm install and npm run build.
16. Fix all build errors before finishing.
